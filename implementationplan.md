## Overview & Role Responsibility

As **P2 (Retrieval / Fundamentals Lead)**, your core mission across the project stages is to establish the **Retrieval-Augmented Generation (RAG)** pipeline and build the **RAG-grounded Fundamental Agent**. You ensure that market insights and agent recommendations are strictly backed by verifiable corporate filings (SEBI disclosures, earnings call transcripts, financial statements) with explicit source attribution at every step.

---

## User Review Required

> [!IMPORTANT]
> **Source Attribution Contract:** Every output generated by `fundamental_agent.py` must include a `citations` array with traceable source metadata (`source_doc`, `excerpt`, `page_or_section`). This feeds directly into P4's frontend `AgentTracePanel` and `CitationPopover`.

> [!NOTE]
> For fast-track/hackathon execution, `retriever.py` uses keyword and semantic matching over a targeted document corpus. In full build mode, `loader.py`, `chunker.py`, `embedder.py`, and `vector_store.py` process raw PDFs into ChromaDB using HuggingFace embeddings (`all-MiniLM-L6-v2`).

## Stage-Wise Development Plan for P2

---

### Stage 1 — Foundation: Document Ingestion & RAG Data Layer

#### Objectives
Build the ingestion pipeline and vector search mechanism to store and retrieve regulatory disclosures.

#### Tasks & Components
1. **Document Loading (`backend/services/document_ingestion/loader.py`)**
   - Implement loaders for PDFs and text transcripts using PyMuPDF / LangChain document loaders.
2. **Text Chunking (`backend/services/document_ingestion/chunker.py`)**
   - Split filings into semantically coherent chunks using `RecursiveCharacterTextSplitter` (chunk size ~500-1000 chars, overlap ~100 chars).
3. **Embedding Generation (`backend/services/document_ingestion/embedder.py`)**
   - Generate local embeddings via `sentence-transformers` (`all-MiniLM-L6-v2`) — 100% free local execution.
4. **Vector DB Storage (`backend/services/document_ingestion/vector_store.py`)**
   - Upsert document chunks and metadata into ChromaDB (embedded mode).
   - Expose similarity search interface `search(ticker: str, query: str, top_k: int = 3) -> List[Dict]`.
5. **Standalone Ingestion Script (`backend/scripts/ingest.py`)**
   - CLI script to ingest sample SEBI filings and earnings transcripts into ChromaDB.

#### Deliverables
- `scripts/ingest.py` populates ChromaDB.
- Manual vector query returns relevant chunks with source metadata (`document_name`, `page`, `chunk_id`).

---

### Stage 2 — Multi-Agent Intelligence: Fundamental Agent & Citation Pipeline

#### Objectives
Construct the RAG-grounded Fundamental Agent, retriever interface, and source attribution tracker.

#### Tasks & Components
1. **Shared Data Contracts (`backend/orchestrator/contracts.py`)**
   - Collaborate with P1, P3, P4 to lock Pydantic schemas:
     - `Citation`: `source_doc: str`, `excerpt: str`, `page_or_section: Optional[str]`
     - `FundamentalSignal`: `ticker: str`, `valuation_assessment: str`, `key_risks: List[str]`, `citations: List[Citation]`, `confidence: float`
2. **Retriever Service (`backend/services/rag/retriever.py`)**
   - Connect to Stage 1 vector store (or fallback snippet dataset) filtered by target `ticker`.
   - Function `retrieve_chunks(ticker: str, query: str, top_k: int = 3) -> List[Dict]`.
3. **RAG Prompt Construction (`backend/services/rag/prompt_builder.py`)**
   - Inject retrieved document context into LLM prompt with explicit grounding constraints ("Answer using ONLY provided context; cite sources").
4. **Citation Extraction & Tracking (`backend/services/rag/citation_tracker.py`)**
   - Map claims extracted from LLM responses back to document chunk metadata.
5. **Fundamental Agent Implementation (`backend/agents/fundamental_agent.py`)**
   - Execute Groq API completion (Llama-3.3-70B) with structured JSON output matching `FundamentalSignal`.
   - Implement rate-limit/timeout retry logic and fallback to low-confidence default when filings are missing.

#### Deliverables
- `python -m backend.agents.fundamental_agent --ticker RELIANCE` returns a structured signal grounded in filings with explicit citations.

---

### Stage 3 — Personalization, API Integration & Streaming Support

#### Objectives
Expose the RAG engine and fundamental insights to the API layer and support real-time agent trace streaming.

#### Tasks & Components
1. **Document Ingestion Endpoint (`backend/api/routes/documents.py`)** *(Optional/Full)*
   - `POST /api/documents/ingest` endpoint enabling on-demand PDF filing upload and vector indexing.
2. **Analysis Route Integration (`backend/api/routes/agents.py`)**
   - Integrate `fundamental_agent` execution into the primary `/api/analyze` request pipeline managed by P3/P4.
3. **Agent Trace Streaming Support (`backend/api/ws/agent_trace.py`)**
   - Emit intermediate trace events (`"Fundamental Agent searching SEBI filings..."`, `"Extracted 3 citations from Q3 earnings transcript"`) over WebSocket.
4. **Context Injection for Personalization**
   - Ensure retrieved fundamental risks are compatible with P3's `profile_injector.py` (e.g. flagging high-debt risks specifically for conservative user profiles).

#### Deliverables
- Fundamental analysis and citations flow seamlessly through `POST /api/analyze` and stream live agent reasoning events.

---

### Stage 4 — UI Reasoning View, Metrics & E2E Validation

#### Objectives
Support UI citation popovers, log fundamental agent performance metrics, and validate end-to-end pipeline robustness.

#### Tasks & Components
1. **Citation & Trace UI Support (`frontend/src/components/AgentTracePanel.jsx` & `CitationPopover.jsx`)**
   - Ensure `fundamental_agent` output format correctly populates P4's expandable trace panel and hoverable citation popovers.
2. **Conflict Resolution Validation (`backend/orchestrator/conflict_resolver.py` / `tests/e2e/test_conflict.py`)**
   - Test scenarios where Fundamental Agent signals bearish risk (e.g., high debt in filing) while Technical Agent signals bullish momentum, ensuring conflict is highlighted rather than obscured.
3. **Degraded-Data & Missing Filing Handling (`backend/tests/e2e/test_degraded_mode.py`)**
   - Validate system behavior when no filings exist for a ticker: agent sets `confidence: 0.0` and flags missing document gracefully without failing the synthesis pipeline.
4. **Session Metrics & Accuracy (`backend/services/logging/metrics_store.py`)**
   - Capture fundamental agent execution latency and citation count per session.

#### Deliverables
- Full end-to-end verification: input ticker → retrieve filings → run fundamental agent → stream reasoning & citations to frontend → resolve conflicts gracefully.
